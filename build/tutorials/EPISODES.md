# Screenplay Studio: "Hard Problems" tutorial series

Each episode opens with a real production problem, then walks through the tools that solve it on the real app UI (project *Nasjonens Siste Rangering*). It shows where to click, what each control does, and where else the tool is useful. Format: 4K cinemascope (3840×1608), macOS narrator plus on-screen annotation, about 4–6 minutes per episode.
